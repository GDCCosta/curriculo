### Parque de Material Aeronáutico de São Paulo — PAMA SP <span class="periodo">2019 – 2023</span>
**Cargo: Engenheiro Metalúrgico/Dados**

No parque de material aeronáutico, juntamente com o gestor, tive o desafio de implementar na engenharia metalúrgica a linguagem de programação Python para otimizar o processamento de dados do sistema.

**Atividades específicas:**

- **Definição do objetivo da análise:** analisar os dados utilizando Python para aprovação dos lotes de peças fabricados pelo fornecedor, através de dados como microestrutura, tratamento térmico e dimensão, com o objetivo de otimizar o tempo de aprovação dos lotes.
- **Coleta e armazenamento dos dados:** os dados foram extraídos do banco de dados interno através de um arquivo CSV.
- **Pré-processamento dos dados:** utilizando Python, realizou-se a leitura do arquivo CSV, a padronização dos dados e a limpeza dos campos vazios e nulos.
- **Seleção das técnicas de análise:** verificação da porcentagem máxima de peças fora do padrão.
- **Realização da análise:** com os dados coletados, armazenados e pré-processados, foi possível realizar a análise para aprovação ou rejeição dos lotes de peças.
- **Interpretação dos resultados e tomada de decisão:** após a interpretação dos resultados, foi possível saber a quantidade de lotes aprovados, atualizar o sistema de logística e estoque e utilizar as peças aprovadas, otimizando o tempo de manutenção e o funcionamento das aeronaves. Essa análise reduziu em **30% o tempo de verificação dos lotes**. Em seguida, foi gerado relatório em Power BI através de dashboards para apoiar a tomada de decisão sobre a solicitação de novas peças e o prazo necessário, sem prejudicar o estoque nem deixar as aeronaves sem manutenção.
